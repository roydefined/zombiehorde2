
==========================================
ZOMBIE HORDE 2 STARTER PACKAGE
==========================================

Welcome to Zombie Horde 2!
This package includes everything you need to play the mod.
No prior installation is required.


------------------------------------------------------------
WHAT'S INCLUDED
------------------------------------------------------------

This zip contains three main components:

1. ZANDRONUM
   The engine that runs the game.
   It's a modern multiplayer-focused port of the Doom engine
   that supports online play and advanced mods.

2. DOOMSEEKER
   The server browser used to find and join online games.
   You will use this to find multiplayer servers.

3. WADS
   The folder containing all required mod files.
   Inside you'll find:
        - A pk3 of the mod itself.
	      It's like a ZIP containing all the game's data and assets.
        - fakeiwad.wad, which is a completely empty file that acts as a
          placeholder base resource. It satisfies Zandronum's requirement
          for an IWAD so Zombie Horde 2 can be played as a standalone mod.


------------------------------------------------------------
INITIAL SETUP
------------------------------------------------------------

When you open Doomseeker for the first time, it will likely ask
you to configure it. If not, open the menu and navigate to 'Options -> Configure'.

There are two important steps here:

1. CONFIGURE ZANDRONUM
    - Select "Zandronum" under the "Games" section on the left.
    - Find the field called 'Path to game executable'.
    - Browse or type the path to the Zandronum executable included
	  with the mod pack.
    - Click 'Apply' to save.

2. CONFIGURE WAD PATHS
    - In the same configuration window, go to File Paths.
    - Here you tell Doomseeker where to find mod files (.wad / .pk3).
	  You have two options:
          1. Move the mod file and 'fakeiwad.pk3' file into an already configured folder.
		  2. Add the existing '/Wads' folder to this list.

Once added, Doomseeker will automatically detect and use these files.


------------------------------------------------------------
READY TO PLAY!
------------------------------------------------------------

Return to the main Doomseeker window.

At the top right Doomseeker provides a search bar.
You can search for the mod using keywords like 'Zombie Horde 2' and 'ZH2'.

Doomseeker will show all available servers running the mod.
If your setup is correct, double-click any server to join and play.


------------------------------------------------------------
VERIFYING YOUR SETUP
------------------------------------------------------------

To confirm that Doomseeker recognizes your mod files:
    1. Hover your mouse over the server's IWAD and WAD list.
    2. Each file shows a colored indicator.
       GREEN means the file is found and valid.
       RED means the file missing or not found.

If both the mod file and 'fakeiwad.pk3' file are green,
everything is configured correctly.


------------------------------------------------------------
HELP AND SUPPORT
------------------------------------------------------------

If you encounter issues:
- Make sure the '/Wads' folder path is added under File Paths.
- Verify that zandronum.exe is properly linked.
