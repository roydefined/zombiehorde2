Zombie Horde 2, by Fused / RoyDefined

This file is an optional download intended for server owners.
It adds extra radio tracks to the existing selection available to players.
All tracks included in this package were created specifically for Zombie Horde 2.

Radio tracks are created and provided by Rady-MIDI, a.k.a. Proxy-MIDI.

GAME INFORMATION
================================================================================

Engine
    Zombie Horde 2 makes use of the Zandronum engine.
    To play, you must use Zandronum 3.3, provided here: https://zandronum.com/download.

Compiler
    Build using zt-BCC, a form of the BCC compiler.
    https://github.com/zeta-group/zt-bcc
    
Renderer
    Zombie Horde 2 requires use of OpenGL rendering
    Software mode rendering is playable but heavily advices against.

Building
    Building this mod is done using PubDoomer to compile and pack the project.
    https://github.com/RoyDefined/PubDoomer
