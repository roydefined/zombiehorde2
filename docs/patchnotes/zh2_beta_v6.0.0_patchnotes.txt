Repository changes
------------------------------------------------

- The repository has more Python files for managing the project:
    - A Python script that handles the compression of sounds using ffmpeg.
    - A Python script that handles the compression of graphics using oxipng.
    - A Python script that handles the creation of tags on the current commit based on the current version.
    - A Python script that handles the updating of the mod version across multiple files to avoid having to updating multiple locations.
- Moved contents used as templates from the build/ folder to the templates/ folder.
- Added a version.txt file which will contain the current version of the mod. One of the new Python scripts will use this file as reference when updating.
- Builds made of the mod through PubDoomer in this project are now in lowercase rather than PascalCase.
