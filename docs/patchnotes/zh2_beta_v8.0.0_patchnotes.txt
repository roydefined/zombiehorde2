Map changes
------------------------------------------------

* * Modern map mapslot migration * *
Four modern maps have been migrated to a new mapslot to properly reserve the old mapslots for possible future modern reworks of these maps.
The modern maps that have been migrated did not represent the modern rework of the map (e.g. ZE07M was not actually a modern rework of ZE07).
The maps have been moved to a higher mapslot, and the old mapslots are now unused.
The following maps have been migrated:
- ZE07M "Island Escape" is now ZE33M.
- ZE08M "Military Base Escape" is now ZE34M.
- ZM07M "The Warehouses" is now ZM32M.
- ZM08M "Napalm in the Morning" is now ZM33M.

Repository changes
------------------------------------------------
- Improved the tooling withing the project, filling gaps and making it easier to run the tool and catch issues.
    - `find_texture_duplicates.py` now correctly truncates lump names to 8 characters, so textures that have a longer name correctly get caught as duplicates.
    - Added `find_sprite_duplicates.py`, which is a tool similar to `find_texture_duplicates.py`, finding duplicates but for sprites (including rotations).
    - Added `validate_sprite_names.py` and `validate_texture_names.py` as two scripts that validate the naming of sprites and textures and reports invalid names.
    - Added `find_lump_path_duplicates.py` as a way to find duplicate lumps based on relative paths.
    - Added `validate_build.py` as a master script to validate the project as a whole by invoking all validation scripts the project now has.
- Added a `--verbose` option for scripts that use the logging in the tooling. If set, debug logging will be output.
  This means debug logging is now turned off by default.
- Tooling in general has been improved to support verbose logging.
- `build_config_file.py`, `create_tag.py` and `play_local_server.py` now make use of the logging system.
- Fixed `play_local_server.py` not properly setting `sv_maxclients`.
- `play_local_server.py` now loads in optional `host-testing.cfg` which applies extra parameters for testing. For now this is only `sv_maxclientsperip 64`.
- `play_local_server.py` now loads all radio tracks unless otherwise specified.
- Updated `play_local_server.py` with a client count parameter. If unset, the script asks for the number of clients. It will open this many instances of Zandronum.
