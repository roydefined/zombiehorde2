Mod improvements
------------------------------------------------

 * * New client lock system * *
A new system has been added which improves how the mod can lock the client and prevent them from changing their angle or pitch.
This new system replaces the old "totally freeze player" mechanic which has a risk of being overwritten.
Additionally, you are now allowed to walk around when you are in the client consolidation menu or the admin menu.
Should this system not work for you and possibly block your movement or firing,
then you can now use the new "unlock player" menu option in the debug menu of ZH2.
The game now also uses this system when in the voting state.
 
Map improvements
------------------------------------------------

 * * ZTele fixes * *
A lot of survival maps did not have a working ztele despite these implementing it.
This has been fixed by properly migrating these over to use the new ZH2 system.
The following maps have been changed:
ZM08, ZM11, ZM13, ZM15, ZM17, ZM21 & ZM25

Other mod changes
------------------------------------------------

- The mod source has gone a refactor in its formatting to better enforce various formatting rules.
- Prevent possible future runaway errors in map parsing if it grows too big.
- Improve how the game waits for itself to load.
- Turned off falldamage caused by dropping into one of the holes on ZM08.
- The well in ZM02 now teleports zombies out instead of forcing them to use a ztele.
- Fix ZE12 music not working correctly.
- Fix issue where weaponry can unintentionally skip their select state.
- Increased the fire grenade spawn height to match the original bounds.
- Fix a few instances where the code would count and include spectating bots when it should only include playing bots.
- Added energy drinks to the reward pool.
- The "Auto use consumables" setting has now been separated to individual items (medikits, kevlars & energy drinks).
- Fix client consolidation having bad offsets.
- General improvements to the client consolidation window.
- The notice message informing of settings to change has been improved.
- Improved the full server cooldown code and fix it waiting more maps that intended.
- Fix HUD not showing the correct skin icon when wieling the fire grenade.
- The full server cooldown now waits 2 maps by default before triggering again.
- The Zombie Horde 2 menu now has a new menu in which all ZH2 keybinds can be configured.
- The voting screen now uses a new system to render the black background.
- The translucent ally system now properly handles spectating and adjusts as required.
- The footstep system now also properly handles spectating and will properly play depending on who you spectate.
- A lot of maps have has their texture offsetting fixed/improved. Most of these occured during migration but some were also bugged in ZH1.
- Fix an issue with ZM25's blue skull door not having a lock.
- Fix an issue with ZM25's Jack's gun being grabbable by bumping into the wall.
- Fixed issues with the mod double defining the "0522" and "0545" textures.
- ZM08's vent after the second resist has been widened to allow players to walk past eachother.
