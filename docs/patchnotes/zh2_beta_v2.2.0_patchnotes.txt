Mod improvements
------------------------------------------------

 * * New client lock system * *
A new system has been added which improves how the mod can lock the client and prevent them from changing their angle or pitch.
This new system replaces the old "totally freeze player" mechanic which has a risk of being overwritten.
Additionally, you are now allowed to walk around when you are in the client consolidation menu or the admin menu.
Should this system not work for you and possibly block your movement or firing,
then you can now use the new "unlock player" menu option in the debug menu of ZH2.
 
Map improvements
------------------------------------------------

 * * ZTele fixes * *
A lot of survival maps did not have a working ztele despite these implementing it.
This has been fixed by properly migrating these over to use the new ZH2 system.
The following maps have been changed:
ZM08, ZM11, ZM13, ZM15, ZM17, ZM21 & ZM25

Other mod changes
------------------------------------------------

- The mod source has gone a refactor in its formatting to better enforce various formatting rules.
- Prevent possible future runaway errors in map parsing if it grows too big.
- Improve how the game waits for itself to load.
- Turned off falldamage caused by dropping into one of the holes on ZM08.
- The well in ZM02 now teleports zombies out instead of forcing them to use a ztele.
- Fix ZE12 music not working correctly.
- Fix issue where weaponry can unintentionally skip their select state.
- Increased the fire grenade spawn height to match the original bounds.
