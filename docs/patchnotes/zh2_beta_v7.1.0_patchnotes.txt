New features
------------------------------------------------

* * Improved skin-dependent weapon spawn replacement * *
The system that ensures weapons on the spawn are placed for the correct skin (currently either legacy or modern) has been improved.
The system now supports a step that transfers over the special and the arguments that a weapon might have defined on a map.
This solves an issue that has been reported in which weapons no longer had this data as the skin-specific spawns never retrieved them.
For example, weapons might have defined a script to invoke on pickup, and this was no longer the case.
The system now supports a proper way to store, transfer, and reapply this information to fix the issue.
Any maps that make sure of this feature will now work correctly and the behavior is fixed.
Affected maps: ZE03, ZE03M, ZE17, ZE28, ZM13, ZM13M, ZM15, ZM25.

Other mod changes
------------------------------------------------
- Fixed LOADACS not loading the ACS correctly for legacy and modern ACS.
- Fixed the special troop soldiers showing as a water splash instead of their own sprite.
- Fixed actors placed in the map not being set up properly in some cases. Notably this broke after the map was reset,
  for example when the game was started using "request game start". After a reset, the mod set these actors up before
  they had spawned again. It now waits until they have. This concerned two groups of actors:
    - Weapons were not replaced with their pickups. They still showed up, but could not be picked up.
    - Zombie teleport spots were not set up, so zombies could not teleport.
- Fixed unintentional warnings with radio broadcasters when they die.
