Map changes
------------------------------------------------

Other mod changes
------------------------------------------------
- Fixed LOADACS not loading the ACS correctly for legacy and modern ACS.
- Fixed the special troop soldiers showing as a water splash instead of their own sprite.
- Fixed actors placed in the map not being set up properly in some cases. Notably this broke after the map was reset,
  for example when the game was started using "request game start". After a reset, the mod set these actors up before
  they had spawned again. It now waits until they have. This concerned two groups of actors:
    - Weapons were not replaced with their pickups. They still showed up, but could not be picked up.
    - Zombie teleport spots were not set up, so zombies could not teleport.
- Fixed unintentional warnings with radio broadcasters when they die.
