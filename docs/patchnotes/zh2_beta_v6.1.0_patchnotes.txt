Map changes
------------------------------------------------

* * Fixed unpickable weapons spawned by maps at runtime * *
Several maps spawned or gave weapons at runtime using a placeholder class instead of the real pickup, making them impossible to pick up. Fixed on all affected maps.

- [ZE13M]: Fixed Jack's Gun, the double shotgun and the radio being unpickable/unownable in the shop.
- [ZE17]:  Fixed the secret room's Jack's Gun being unpickable.
- [ZE18]:  Fixed the safe zone's Jack's Gun spawn being unpickable.
- [ZE20]:  Fixed the grenade generator and water trap's fire grenade being unpickable.
- [ZE20B]: Fixed the grenade generator and water trap's fire grenade being unpickable.
- [ZM06]:  Fixed the secret room's Jack's Gun being unpickable.
- [ZM06M]: Fixed Jack's Gun, double shotgun and fire grenade loot drops being unpickable.
- [ZM09]:  Fixed the super shotgun secret spawn being unpickable.
- [ZM16]:  Fixed the armory's Jack's Gun and double shotgun rewards being unpickable.
- [ZM18]:  Fixed the generator loot's fire grenade, Jack's Gun and double shotgun being unpickable.
- [ZM20]:  Fixed the hunter dog's Jack's Gun drop being unpickable.

API changes (Could contain breaking changes for mappers. Make sure to check this list for migrations)
------------------------------------------------

* * New `Weapon::GetWeaponSpawnClassName` function * *
Resolves a weapon type to the real pickup to spawn. This function should be used by players to resolve a weapon spawn instead of using the direct name.
This prevents skin-specific issues where a spawn might end up with the wrong skin.
This function always ensures the correct spawn can be resolved.

Other mod changes
------------------------------------------------

- Fixed fire grenades dropped on infection being unpickable by humans.
- Fixed an issue with internal move checks not accounting for joystick input.
  This, for example, caused issued with the new AFK prevention system.
- Fixed anti-SR50 not triggering when using analog input.
- Fixed the round-start AFK bar showing even when `sv_zh2_afkmoveatroundstart` is disabled.
