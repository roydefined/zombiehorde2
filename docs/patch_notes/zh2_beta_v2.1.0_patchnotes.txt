Map improvements
------------------------------------------------

 * * Ladder fixes * *
A lot of maps had ladders that were not working. This apparently happened with the release of Zandronum 3.0, and it affected ladders that did not have an actual midtexture to bump into.
This has been fixed by changing these to properly collide with said ladders so the user can climb them.
The following maps have been changed:
ZE04, ZE19, ZM08M, ZM14, ZM18, ZM21 & ZM25

 * * Crusher fixes * *
A lot of maps had crushers that were not working. The crushers stopped working in ZH2 due to conversion changing the crusher type as Hexen format maps used a different system.
This has been fixed by correcting the crusher type. Note that an additional change has been made on most crushers to ensure that they do not perform excessive damage.
The reduction of the damage on crushers is an attempt to reduce insta-killing factors on maps. To support this change various crushers now have added tag waiting to ensure they do not break.
The following maps have been changed:
ZE02, ZE02B, ZE05M, ZE06, ZE06M, ZE08M, ZE11, ZE12, ZE15, ZE16, ZE17, ZE18, ZE19, ZE21, ZE22, ZE23, ZE25, ZE26, ZE27, ZE29 & ZE30

Other mod changes

- Removed an insta-killing floor on ZE25 at the start of the map.
